# 🔐 Projeto de Aprendizado: Spring Security e Desenvolvimento Backend

## 🎓 Objetivo do Projeto
Um projeto dedicado a aprofundar conhecimentos em Spring Security, desenvolvimento backend e boas práticas de programação Java.

## 📚 Conceitos Principais Explorados

### 1. 🗄️ Persistência de Dados
- Utilização de Spring Data JPA
- Migrations de banco de dados com Flyway
- Trabalho com diferentes bancos de dados (PostgreSQL e H2)

### 2. 🔒 Segurança e Autenticação
- Implementação de filtros de segurança personalizados
- Autenticação via tokens JWT
- Proteção de endpoints
- Configuração avançada de Spring Security

### 3. 🌐 Desenvolvimento de APIs
- Criação de APIs RESTful
- Tratamento de exceções com ExceptionHandler
- Boas práticas de desenvolvimento backend

### 4. 🧪 Testes e Qualidade
- Testes unitários com JUnit
- Mocking de dependências com Mockito
- Cobertura de código e casos de teste

## 🛠️ Principais Annotations Exploradas
- `@Entity`
- `@Repository`
- `@Service`
- `@RestController`
- `@Autowired`
- `@ConfigurationProperties`
- `@ExceptionHandler`
- Annotations de Spring Security
